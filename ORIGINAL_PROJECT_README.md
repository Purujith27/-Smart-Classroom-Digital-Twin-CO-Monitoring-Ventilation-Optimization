# Smart Classroom Digital Twin

- `Smart_Classroom_Digital_Twin.ipynb`: runnable notebook for Google Colab/Jupyter
- `Technical_Report.pdf`: technical report with generated figures and scorecard
- `dashboard.html`: open in a browser; keep `outputs/` beside it
- `outputs/simulation_data.csv`: simulated minute-level data
- `outputs/*.png`: generated charts

All parameters are illustrative, not real campus measurements. Do not connect to real HVAC equipment without field calibration, validation and safety review.
